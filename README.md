# 📊 Motorola Sales Analytics Dashboard

An interactive **Power BI Sales Analytics Dashboard** built to analyze sales performance, product performance, customer behavior, payment methods, geographical distribution, and sales trends.

The dashboard transforms transactional sales data into meaningful business insights using **Power BI, Power Query, DAX, and interactive data visualizations**.

---

## 📌 Project Overview

The Motorola Sales Analytics Dashboard provides an interactive view of sales performance across different products, customers, cities, payment methods, and time periods.

The dashboard allows users to dynamically explore the data using multiple filters and interactive visualizations.

### Key Metrics

- 💰 Total Sales
- 📦 Total Quantity
- 🧾 Total Transactions
- 💵 Average Price

All key metrics and visualizations dynamically update based on the selected filters.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze overall sales performance
- Identify high-performing products
- Analyze product quantity and revenue
- Understand customer purchasing behavior
- Analyze payment method preferences
- Analyze daily and monthly sales trends
- Visualize geographical sales distribution
- Build an interactive business intelligence dashboard

---

# ✨ Dashboard Features

## 💰 1. Key Performance Indicators

The dashboard contains four major KPI cards:

### Total Sales

Displays the total revenue generated from all transactions.

### Total Quantity

Displays the total number of products sold.

### Transactions

Displays the number of transactions in the dataset.

### Average Price

Displays the average unit price of products.

These values dynamically change based on the selected filters.

## 🔍 3. Interactive Filters

The dashboard contains the following filters:

- E-Reader

- Headphones

### Payment Type

- UPI

### Customer Name

## 🗺️ 4. Total Sales by City

The geographical map visualizes sales distribution across cities.

## 📈 5. Total Quantity Trend

A line chart displays the total quantity sold over the selected period.
